Положите в эту папку mp3-файлы для веб-уведомлений:

- `ticket-new.mp3` — новая обычная заявка;
- `ticket-emergency.mp3` — новая аварийная заявка;
- `complaint-auditor.mp3` — новая жалоба для аудитора/администратора;
- `complaint-dispatcher.mp3` — новая жалоба для диспетчера;
- `complaint-message.mp3` — новое сообщение в переписке по жалобе;
- `resident-update.mp3` — обновления для жителя: статусы заявок, решения по жалобам и сообщения в жалобах.

Если файла нет или браузер заблокировал автозвук, веб-версия воспроизведёт короткий резервный тон.
